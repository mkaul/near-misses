# "near-misses" Repo 
- 4 interactive maps of Near Misses
- Editor to change existing maps and to create your own map

## A near miss is still a miss.
Some views lie so close to real insight that you can hardly tell them apart. That is exactly why they lead astray. These maps show 84 such near misses from Buddhism, Christianity, Islam and today’s nonduality, each with the real thing it imitates.
